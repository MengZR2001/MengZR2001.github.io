# Zhaorui Meng's Academic Homepage

A responsive, dependency-free academic website for GitHub Pages.

Website: https://mengzr2001.github.io/

## Local Preview

Run `python -m http.server 8000` from this directory, then open http://localhost:8000.
The page also works by opening `index.html` directly.

## Editing

- `index.html`: biography, publications, profile links, experience, and education.
- `style.css`: layout, typography, responsive styles, and print styles.
- `assets/portrait.jpg`: optimized portrait, with no original EXIF metadata.

No JavaScript, analytics, third-party fonts, or build step is required.

## Publishing

Create a public repository named `MengZR2001.github.io` under `MengZR2001` and push these files to `main`.
In Settings > Pages, select **Deploy from a branch**, **main**, and **/(root)**.
